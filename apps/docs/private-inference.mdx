<Note>
  **Moved 2026-08-01.** Private Inference — the OpenAI-compatible API, the model
  catalog, API keys, credit, and confidential (GPU-TEE) receipts — is an
  **[Audric](https://audric.ai)** product. It is no longer served from
  `api.t2000.ai`, and there is **no redirect**: those paths return `410 Gone`.
</Note>

## Where things went

| What | Where it lives now |
|---|---|
| OpenAI-compatible API | `https://api.audric.ai/v1` |
| Model catalog + pricing | `GET https://api.audric.ai/v1/models` |
| API keys + credit | [audric.ai](https://audric.ai) — minting a key requires **$5** of credit |
| Confidential receipts + verify | Audric, in-app |

```bash
curl https://api.audric.ai/v1/models

curl https://api.audric.ai/v1/chat/completions \
  -H "Authorization: Bearer $AUDRIC_API_KEY" \
  -H "content-type: application/json" \
  -d '{"model":"openai/gpt-oss-120b","messages":[{"role":"user","content":"Hello"}]}'
```

Point a coding tool at it with [`t2 connect`](/cli-reference) — it writes
`api.audric.ai/v1` and prompts for your Audric key. A config written before the
cutover still names `api.t2000.ai`; re-run `t2 connect` to rewrite it.
